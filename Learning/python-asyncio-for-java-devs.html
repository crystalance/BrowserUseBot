1. The core mental shift

JavaPython asyncio
WorkersMany threadsOne thread
SwitchingOS preempts anytimeOnly at await (cooperative)
Shared dataNeeds locks / synchronizedUsually no locks (one thread)
StyleParallelismConcurrency (1 worker switching fast)

Shift: one thread juggles many tasks. It runs one task until that task voluntarily says "I'm waiting" via await, then runs others. No preemption.

2. What await means

x = await fetchData()   # run it, suspend here until done, free the thread, then x = real value

Like Java CompletableFuture chaining but top-to-bottom:

// Java
fetchData().thenCompose(x -> process(x)).thenAccept(r -> use(r));

# Python
x = await fetchData()
r = await process(x)
use(r)

await ≈ future.join()/get() — but it does not block the thread; it frees it for other tasks.

3. What if you DROP await?

x = fetchData()   # x is a <coroutine object>, NOTHING ran yet
r = process(x)    # passing a recipe as data → bug
use(r)            # ⚠ warning: coroutine 'fetchData' was never awaited

A bare call returns a paused recipe, not the result. Like building a CompletableFuture and never joining it. await does two jobs: drive to completion + unwrap result.

5. Event loop = 1 thread + work queue

Like an ExecutorService with exactly one worker: a task runs until await, parks itself ("wake me when this Future is done"), yields, worker grabs next. await event.wait() = "park me; mark ready on event.set()" — Java's wait()/notify() without blocking a thread.

6. Pause/resume via asyncio.Event (our login handoff)

async def run():
    while not done:
        if paused:
            await event.wait()   # parks task, frees thread
        await step()

def resume():
    event.set()                  # sync flip → marks parked task ready
  • pause()/resume() are sync because set()/clear() just flip a flag.
  • Both run on the same thread, so resume() can't interrupt run mid-line → no lock needed.
  • Exception: cross-thread → use loop.call_soon_threadsafe(event.set).
One line: await = cooperative pause point; event loop = one thread running tasks until they await; asyncio.Event = wait()/notify() without blocking a thread. Concurrency, not parallelism.
